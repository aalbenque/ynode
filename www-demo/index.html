What's running under the hood

⚡
Pure Bash
No compiled server binary. Everything is shell scripts.
🔒
SSL / TLS
HTTPS via socat OPENSSL-LISTEN.
🐘
FastCGI / PHP-FPM
Routes .php requests over Unix socket.
📁
Static file serving
ETag, Last-Modified, Range, 304 Not Modified.
🔑
HTTP Basic Auth
Per-directory protection via .ynpasswd.
🔌
Module system
.ynaccess picks the handler per path.

Routing rules active on this site

Defined in www-demo/.ynaccess

Path pattern Module / action Notes
^/$ fcgi Rewrites to /index.php, sent to PHP-FPM
^/restricted auth_basic HTTP Basic Auth · realm: Restricted Area
/.ynaccess$ 404 Config files are hidden from the web
/ping ping Health check · always returns 200 OK
/test_cgi.php cgi Executed via php-cgi (CGI mode)
*.php (other) deny 403 Forbidden - only index.php is public
everything else static Cache-Control: max-age=31536000
